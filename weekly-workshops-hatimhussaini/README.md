# COMP2110 Weekly Workshops

This repository serves as a comprehensive collection of completed weekly workshop tasks for COMP2110 Web Technology. Each week's work is organized into a dedicated `weekXX` subdirectory (e.g., `week01`, `week02`, etc.), demonstrating progress and learning throughout the semester.

### Repository Structure

Each `weekXX` folder contains:
-   The assigned tasks and their solutions.
-   A `README.md` file detailing the specific tasks for that week, any challenges encountered, and how feedback from classes and revisions has been incorporated.
