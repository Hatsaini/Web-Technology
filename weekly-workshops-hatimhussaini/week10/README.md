# COMP2110 Week 10: Web Application Development Process - Planning and Coordination

This week's workshop provided hands-on experience with the early stages of a structured web application development process. The focus was on project planning, requirements analysis, timeline estimation, and technical planning for a chosen web application idea. This involved collaborative group work and individual contributions to set up the foundation for a potential project.


## 1. Project Description

**Problem solved:**  
Helps users organize and track personal projects, tasks, and deadlines in one place—no more scattered notes or forgotten tasks.

**Target users:**  
Students, hobbyists, and anyone managing small projects.

**Key features:**  
- **Project dashboard:** View all projects at a glance.  
- **Task management:** Add, edit, and delete tasks.  
- **Deadline reminders:** See and get notified about upcoming deadlines.


## 2. Requirements Analysis

**Functional requirements:**  
1. **CRUD for projects:** Create, read, update, and delete projects.
2. **CRUD for tasks:** Add, edit, and delete tasks within projects.
3. **Deadline reminders:** Display and notify about upcoming deadlines.

**Non-functional requirements:**  
1. **Usability:** Simple and intuitive for all users.
2. **Security:** Protect user data from unauthorized access.


## 3. Timeline and Task Breakdown

**Team roles:**  
- **Frontend:** UI, dashboard, task management
- **Backend:** Project/task APIs, reminders
- **Database:** Schema, integration, testing

**Estimated hours per area:**  
- **Frontend:** Dashboard (4h), Task UI (4h)
- **Backend:** Project API (4h), Task API (4h), Reminders (2h)
- **Database:** Schema (3h), Integration (3h), Testing (2h)

**Basic timeline:**  
- **Week 1:** Setup, dashboard, project API, database schema
- **Week 2:** Task management, task API, reminders, integration
- **Week 3:** Testing, bug fixes, final touches

## 4. Web Stack

**Frontend:**  
- **HTML, CSS, JavaScript**  
- **React (optional)**

**Backend:**  
- **Node.js, Express**

**Database:**  
- **MongoDB** (or mock data initially)

**Communication:**  
- **HTTP using Fetch API**
