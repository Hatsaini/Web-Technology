# COMP2110 Week 08: Asynchronous JavaScript and API Interactions (Jokes Application)

This week's workshop focused on asynchronous JavaScript programming, particularly using `fetch` to interact with external APIs, and dynamically updating the DOM to display content. The core task involved building a jokes application with two different display modes.

### Tasks Completed:

*   **Task 1: Single Random Joke Display (`index.html`, `script-task1.js`):**
    *   Developed an HTML page (`index.html`) to display a single joke.
    *   Implemented JavaScript (`script-task1.js`) to fetch a random joke from an external API (presumably `https://v2.jokeapi.dev/joke/Any?type=single` or similar) upon a button press.
    *   Dynamically updated the page to display the fetched joke.

*   **Task 2: Multiple Random Jokes List (`index-2.html`, `script-task2.js`):**
    *   Created a separate HTML page (`index-2.html`) to display multiple jokes.
    *   Implemented JavaScript (`script-task2.js`) to fetch 10 random jokes from an API.
    *   Rendered these jokes as a list, with each joke's setup in bold and its punchline on a second line, demonstrating more complex DOM manipulation and data presentation.

*   **Styling (`style.css`):**
    *   Applied basic CSS (`style.css`) to ensure both joke display pages were visually presentable and readable.
