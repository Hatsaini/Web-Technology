Sample question in Workshop:

Consider an HTML page containing a form with id="add-user-form" (having input fields for name and email) and an empty <table> with id="user-table".
(a) (5 marks) Dynamic Table Row Addition:
Write a JavaScript function, addTableRow(name, email), that:
Creates a new table row (<tr>).
Creates two table data cells (<td>), one for name and one for email.
Appends these <td>s to the <tr>.
Appends the new <tr> to the <tbody> of the table with id="user-table".
(b) (5 marks) Form Submission Handling:
Explain how you would modify the add-user-form and use JavaScript to:
Prevent the default form submission.
Retrieve the values from the name and email input fields when the form is submitted.
Call the addTableRow function from part (a) with these retrieved values.
